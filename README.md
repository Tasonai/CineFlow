# 🎬 CineFlow — Единый Онлайн-Кинотеатр для Windows (Poland PL Edition)

Минималистичный агрегатор стриминговых сервисов для **Польши (`PL`)** с нативным плеером **HDRezka** (с обходом гео-блокировок), поддержкой **Netflix, Amazon Prime Video, Disney+, HBO Max, Player.pl**, функцией **Skip Intro**, безопасным для ЕС **4K-стримингом** и автоматической синхронизацией с **Kinorium**.

---

## ✨ Реализованные возможности (MVP)

1. **Единый поиск (`Ctrl + K`) сразу по 6 сервисам:**
   - Поиск на русском, польском и английском языках.
   - Прямая интеграция с **JustWatch GraphQL API (регион `PL`)** для проверки наличия фильма/сериала в Польше на **Netflix**, **Amazon Prime Video**, **Disney+**, **HBO Max** и **Player.pl** + поиск на **HDRezka**.
2. **HDRezka без региональных блокировок в Польше (Split-Proxy):**
   - Декодер обфусцированных потоков `#h...` (Base64 + очистка мусорных маркеров `//_//`).
   - **Split-Proxy (`KZ` / `AM` / `MD`):** запросы к API `ajax/get_cdn_series` идут с заголовками нейтрального региона (обходя европейские DMCA-ограничения *«Это видео недоступно в вашей стране»*), при этом само видео качается напрямую без VPN и без потери скорости, а ваш польский IP сохраняется для `Player.pl` и `Netflix`.
   - Выбор студии озвучки (*HDRezka Studio*, *Кубик в Кубе*, *Red Head Sound*, *TVShows*, *LostFilm*, *Оригинал + Субтитры*).
3. **Авто-пропуск заставок и титров (`Skip Intro` / `Skip Outro`):**
   - Подключение к базе таймкодов **TheIntroDB** + встроенная база сериалов.
   - Всплывающая кнопка **«⏭ Пропустить заставку»** и переключатель **«Авто-пропуск заставки»**.
   - Встроенный пользовательский скрипт для авто-нажатия *Skip Intro / Pomiń czołówkę* в Netflix, Prime Video, Disney+, Max и Player.pl.
4. **Безопасный для Польши и ЕС резервный 4K-стриминг:**
   - Поиск 4K UHD / HDR10 / Dolby Vision / BDRemux раздач через агрегатор **JacRed**.
   - Поддержка режима **Debrid HTTPS (0% P2P Swarm Exposure)** и **TorrServer**.
5. **Интеграция с Kinorium и Авто-отметка «Просмотрено» (85% Scrobbler):**
   - Отображение рейтингов Kinorium, IMDb, Кинопоиска и оценок друзей.
   - Автоматическая отметка фильма/эпизода как **«Просмотрено»** при достижении **85%** хронометража + всплывающее окно оценки от `1` до `10`.

## 🚀 Как запустить

### На Windows 10 / 11:
1. **Быстрый запуск в режиме приложения (Edge WebView2 App Mode с поддержкой Widevine L1 DRM):**
   Дважды кликните по файлу:
   ```
   windows\Start-Cinema-Windows.bat
   ```
2. **Сборка в единый автономный `CineFlow.exe`:**
   Запустите:
   ```
   windows\build-windows-exe.bat
   ```
   Готовый `CineFlow.exe` появится в папке `dist\CineFlow.exe`.

### Локальный запуск (Windows / macOS / Linux):
```bash
python3 server.py
```
После запуска откройте в браузере: **http://127.0.0.1:8765**
